# 快速上手（不用会编程）

这份是「照着点」的版本：从零到**手机每天 15:05 收到一条缠论全览**，大约 30 分钟。
只想先看看它长什么样，跳到 [第 3 步](#第-3-步让它先跑出数据) 就够了，不用装 Hermes。

> 全程不需要写代码。所有 ` ``` ` 里的命令都是**整段复制、粘贴到黑窗口里、回车**。

---

## 第 0 步：准备好这四样

| 要有 | 说明 |
|---|---|
| Windows 电脑 | 能正常开机的就行，不需要显卡 |
| 通达信 PC 客户端（64 位） | 你平时看盘用的那个。默认安装在 `C:\new_tdx64`，装在别处也没关系，后面填一次路径 |
| 自选股里至少 3 只票 | 它就是盯你自选股里的票，不盯别的 |
| 30 分钟 + 一个能收消息的手机 | 推送走 ClawChat（Hermes 的聊天端），没有也能只用「手动看一眼」 |

---

## 第 1 步：装 Python（5 分钟，装过可跳过）

1. 打开 https://www.python.org/downloads/ ，点黄色大按钮下载。
2. 双击安装包，**第一屏底部一定要勾上 `Add python.exe to PATH`**，然后点 `Install Now`。
3. 装完打开「开始菜单 → 输入 `cmd` → 回车」，粘贴这一行验证：

```bash
python --version
```

看到 `Python 3.1x.x` 就成了。**看到 `'python' 不是内部或外部命令`** → 说明第 2 步的勾没打，重装一次 Python。

---

## 第 2 步：把仓库下下来

**不会用 Git 就用这招**：仓库页面右上角绿色 `Code` → `Download ZIP` → 解压到 `E:\Hermes\chanlun-bot`（路径随意，**别放桌面、别带中文和空格**，Windows 路径中文会出各种毛病）。

解压后确认这个文件在：`E:\Hermes\chanlun-bot\agent\chanlun_prep.py`。在这一层就对了。

---

## 第 3 步：让它先跑出数据

在 `chanlun-bot` 文件夹里，**地址栏输入 `cmd` 回车**（或按住 Shift 右键 → 在此处打开命令行），然后整段粘贴：

```bash
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r tdx\requirements.txt
```

装依赖大约 1~2 分钟，最后一行是 `Successfully installed ...` 就好。

接着测行情（这是最容易出错的一步）：

```bash
.venv\Scripts\python.exe tdx\watch.py scan
```

- 看到 `data[ok]` 打头的一行行 → 行情通了。
- 全是 `[timeout]` / `[fail]` → 网络或券商主站问题，换手机热点再试一次；还不行就看 [FAQ](FAQ.md#行情连不上)。

最后跑一次结构计算：

```bash
set TDX_PY=%CD%\.venv\Scripts\python.exe
bash agent\run_scan.sh intraday --force
```

> `bash` 来自 Git for Windows（装 Git 时自带）。没有 `bash` 就先装 Git：https://git-scm.com/download/win ，一路默认下一步。
> 如果你用 PowerShell 而不是 cmd，把 `set TDX_PY=...` 换成 `$env:TDX_PY="$PWD\.venv\Scripts\python.exe"`。

屏幕上会滚出一大段 JSON，包含 `"trading": true` 和 `"stocks": [...]`，每只票有 `zhongshu`、`buy_sell` 字段——**到这一步，核心算法已经在你机器上跑通了**，剩下的只是让它自动跑 + 发到手机。

想看一眼结构图（不需要任何 API）：

```bash
.venv\Scripts\python.exe agent\chan_chart.py 688270
```

它会打印 `written: agent\out\688270_chan.html`，用浏览器打开就是 README 顶上那张图。

## 第 4 步：装上 Hermes（决定「有没有人帮你复核」）

前三步只有脚本，它只会**算**结构。真正判断「这个买点成立不成立」的是跑在 Hermes 上的模型，有它才会推消息。

1. 按 [Hermes 文档](https://hermes-agent.nousresearch.com/docs) 装好并选一个模型（DeepSeek、阿里 token-plan 这些都行）。
2. 建一个 profile 给这个 bot 用，比如 `chanlun`：

```bash
hermes profile create chanlun
```

3. 把这个仓库的技能、人格、配置装进去：

```bash
# 技能（12 个）
mkdir -p "%LOCALAPPDATA%\hermes\profiles\chanlun\skills\finance"
xcopy /E /I /Y skills\finance "%LOCALAPPDATA%\hermes\profiles\chanlun\skills\finance"

# 人格（它「是谁、能做什么、绝不做什么」）
copy SOUL.md "%LOCALAPPDATA%\hermes\profiles\chanlun\SOUL.md"

# 模型 / 平台 / cron 三块配置：照 config\hermes-profile.example.yaml 里的内容，
# 合并进 %LOCALAPPDATA%\hermes\profiles\chanlun\config.yaml
```

4. 验证技能装上了：

```bash
hermes -p chanlun skills list
```

应该能看到 `chanlun-live-scan`、`chanlun-zhongshu-mapper`、`chanlun-buy-sell-points` 等 12 个。

---

## 第 5 步：让它能发到你手机

```bash
copy .env.example .env
```

`agent\config.json` 里改两个值：

| 改哪 | 改成什么 |
|---|---|
| `push.clawchat.profile` | `chanlun`（第 4 步建的 profile 名） |
| `hermes_home` | 你的 Hermes 根目录，一般是 `C:/Users/你的用户名/AppData/Local/hermes` |

然后自检（不发出去就说明通道有问题）：

```bash
hermes -p chanlun send --to clawchat "通道自检：缠论盯盘"
```

手机收到这句 → 通了。没收到 → [FAQ](FAQ.md#推送说-ok-但手机没收到)。

---

## 第 6 步：设两个定时任务

```bash
mkdir "%LOCALAPPDATA%\hermes\profiles\chanlun\scripts"
copy cron\scripts\chanlun_close.sh    "%LOCALAPPDATA%\hermes\profiles\chanlun\scripts\"
copy cron\scripts\chanlun_intraday.sh "%LOCALAPPDATA%\hermes\profiles\chanlun\scripts\"
```

先只建「收盘全览」（每天 15:05 一条，最稳）：

```bash
hermes -p chanlun cron create "5 15 * * 1-5" "读 cron/prompts/close.txt 的内容贴这里" --name 缠论收盘全览 --script chanlun_close.sh --skill chanlun-live-scan --deliver bot-chat --workdir E:/Hermes/chanlun-bot
```

> prompt 很长，别手打：把 `cron\prompts\close.txt` 整个文件内容复制过去替换引号里的部分。
> 更省事的做法是在 Hermes 对话框里直接说「按 cron/README.md 把收盘全览任务建好」，让它替你建。

确认任务在：

```bash
hermes -p chanlun cron list
```

**盘中扫描（每半小时）先别建。** 等收盘全览连续正常 2~3 天，再按 [cron/README.md](../cron/README.md) 加，而且建议先 `--paused`。

## 第 7 步：验收（当天就能验）

今天 15:05 之后，看你手机。正常的一条长这样：

```
缠论盯盘 15:05
上证 30m 第 3 个中枢 [3412.55, 3455.20] 内震荡，未出三类买卖点
━━━ 需要你留意（2 只）━━━
600089 ...
━━━ 已排除（1 只）━━━
002555 ...（一买未过背驰三前提）
非投资建议；仅结构判断
```

**没有任何票要留意时**，它只推一句「今日无候选」——这是正常的，不是坏了。

判断它到底跑没跑，别靠手机，看这三处：

```bash
hermes -p chanlun cron list          # 任务在不在、上次什么时候跑的
hermes -p chanlun cron runs          # 最近几次执行的成败
```

## 第 8 步：日常怎么用

| 我想… | 怎么做 |
|---|---|
| 多加一只票 | 通达信客户端里加进自选股，下一轮自动带上（**不用改配置**） |
| 某只票别烦我 | `agent/config.json` 的 `exclude_codes` 里加代码 |
| 今天不想收 | `hermes -p chanlun cron pause 缠论盘中扫描` |
| 换个模型判 | `hermes -p chanlun` 里说「换 deepseek」，或改 profile 的 `config.yaml` |
| 想手动看一眼现在什么结构 | `.venv\Scripts\python.exe agent\chan_chart.py 代码`，开 HTML |
| 它说的我不认同 | 直接问它「凭什么是二买，把三前提逐条列出来」——它必须列出依据，不许含糊 |

## 出错怎么办

| 屏幕上出现 | 意思 | 怎么办 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 没加进 PATH | 重装 Python，勾 `Add python.exe to PATH` |
| `'bash' 不是内部或外部命令` | 没装 Git for Windows | 装 https://git-scm.com/download/win |
| `ModuleNotFoundError: pytdx` | 依赖装到别的 Python 里了 | 用 `.venv\Scripts\python.exe` 开头执行，别用裸 `python` |
| `自选股为空` | 通达信路径不对 | 确认 `C:\new_tdx64\T0002\blocknew\zxg.blk` 存在；不在这个路径就设 `TDX_DIR` |
| `trading: false` | 现在不是交易时段 | 正常。加 `--force` 用上一交易日数据调试 |
| `30m 结构不足（K线 12 根）` | 主站没给够 K 线 | 先 `tdx\watch.py scan`，再调大 `config.json` 的 `bars_count` |
| `{"ok": true}` 但没收到 | 通道连上了但没送达 | 看 `profiles\chanlun\logs\*.log` 里的 `state=ready` / `ack_received` |
| 每半小时都被叫醒但没内容 | wake gate 被改坏了 | 确认 `chanlun_prep.py --wake-gate` 无候选时真的输出 `{"wakeAgent": false}` |

还解决不了，把**报错原文**（不是截图）贴到 Issue。别贴 `.env`、别贴 `owner.md`、别贴 `config.json` 里的 `hermes_home`。

## 一句话总结

**第 3 步能跑出 JSON** → 算法没问题；**第 5 步手机收到自检消息** → 通道没问题；**第 7 步 15:05 收到全览** → 整套跑通了。三关都过，再谈让它盘中叫你。
