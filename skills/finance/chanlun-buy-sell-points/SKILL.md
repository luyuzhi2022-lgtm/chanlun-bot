# 缠论三类买卖点识别

## R — 来源

依据《教你炒股票17：走势终完美》《20：走势中枢级别扩张及第三类买卖点》《21：买卖点分析的完备性》《53：三类买卖点的再分辨》《61：区间套定位标准图解》。

## I — 方法论骨架

三类买卖点是缠论把结构分析转成交易计划的接口。

**先说清楚"为什么分三类"（ch53）**：一、二、三类买卖点归根结底都可以归到第一类买卖点上，只是级别不同；之所以分三类，是为了**把分析锁定在同一个级别上研究**——否则等于同时用不同倍数的显微镜看走势，"太乱"。

**三条判定主线（原文 crisp 定义，ch101："第一类买卖点就是背驰点，第三类买卖点就是中枢破坏点"）**：
- 第一类：该级别的**趋势背驰点**（→ 需先过 `chanlun-divergence-diagnosis`）。
- 第二类：**第一类买点的次级别回抽结束后、再次探底或回试的那个次级别走势的结束点**（ch101 原文定义），并需满足"不创新高/新低或构成盘整背驰"的确认（ch53）。例：5 分钟底背驰后，一买上去的 1 分钟走势结束，回头必然有一个 1 分钟向下走势，其结束点即二买。
- 第三类：**中枢破坏点**——离开中枢后第一次回试不回中枢，且结构上至少 5 段次级别走势（见 E3）。

**前置过滤（ch21）**：先判断当下走势类型与中枢状态，它会直接排除掉本不该出现的买卖点种类——不要先找点，再找理由。

## A1 — 书中的应用

### 案例一：第三类买点（ch20）
- **问题**: 突破中枢后，哪些回调可以视为延续机会。
- **方法论的使用**: 检查是否为次级别向上离开中枢后的第一次回试，且低点不跌回中枢（不跌破 ZG）。
- **结论**: 只有满足结构条件，才是候选第三类买点。
- **结果**: 避免把任何突破回踩都当成三买。

### 案例二：二卖与三卖重合（ch61，74 点）
- **问题**: 74 点到底是哪种卖点。
- **方法论的使用**: 它既是 69–72 这个中枢的**第三类卖点**，又是 65 起始走势的**第二类卖点**（且必须满足结合律）。
- **结论**: 二、三类买卖点可以重合，且重合后"后面的力度值得关注"（其后出现更大力度的下跌）。
- **结果**: 学会用两种分解交叉验证同一点位，而不是二选一。

### 与相邻 skill 的区分

- 与 `chanlun-divergence-diagnosis`: 一买/一卖需要背驰诊断，本 skill 负责买卖点分类。
- 与 `chanlun-zhongshu-mapper`: 中枢是前置地图，本 skill 判断地图上的位置；中枢**状态**（延续/扩张/新生）由它给。

## E — 可执行步骤

1. **声明非投资建议 + 声明观察级别**
   - 完成标准: 输出只做结构判断，不给买入/卖出指令；明确当下用哪个级别观察。
   - 纪律（ch53）: 一旦选定观察级别，就等于把其次级别当作线段处理；要看该次级别的内部结构（如判断日线三买需看 30 分钟回抽），必须显式切换显微镜倍数并说明。

2. **前置过滤：走势类型 + 中枢状态**
   - 完成标准: 明确中枢区间 [ZD, ZG]、离开方向，以及中枢状态属于**延续 / 扩张 / 新生**（见 `chanlun-zhongshu-mapper`）。
   - 硬规则（ch21）: 中枢延续时，中枢之上不可能有买点；**上涨趋势确定后不可能再有第一、二类买点，只可能有第三类买点**；只有在下跌确立后的中枢下方才可能出现第一类买点。若请求的买卖点种类与走势类型矛盾，直接判"不成立"并说明原因。
   - 硬规则（ch101，中阴限定）: "**只有在这回升的中阴状态下才有第一、二类买点，中阴状态结束后，所有的中枢震荡只存在第三类买卖点以及中枢震荡的买卖点，就不存在第一、二类买卖点了。**"若当下已不在中阴状态，禁止判一、二类买卖点。

3. **匹配买卖点类型**
   - 完成标准: 每个候选信号逐项列出"**满足 / 不满足 / 未知**"，并统一状态用词：`候选 / 已确认 / 已失效 / 信息不足`。按以下规则输出候选类型（每条都要逐项打勾）：
     - **一买/一卖**: 趋势背驰后的转折点（前提：该级别走势为下跌/上涨趋势，且最后一段创新低/新高后力度衰竭）。
     - **二买/二卖**: ① 一买/一卖之后的次级别回抽；② 该回抽**不创新高（卖）/不创新低（买），或构成盘整背驰**。两条同时满足才是二买/二卖；只满足①是"待确认"。
       **二买的三种情况（ch101，必须三选一作答，不要默认"二买必高于一买"）**：
       - **最强**：二买刚好构成"原来下跌的最后一个中枢开始的震荡走势的**第三类买点**"——即二、三类买点合一，一般对应 V 型反转的快速回升，"是最有力度的"。
       - **最弱**：二买**跌破第一类买点**（二买低于一买）——"这是完全可以的"，此处一般构成**盘整背驰**，后面对应从顺势平台到扩张平台等不同走势。
       - **一般**：一、二、三买点依次向上，一个比一个高。
       - 补充（ch101）：站在原来下跌最后一个中枢的角度，一、二、三类买点都可看成中枢震荡的结果，因此**二类与三类之间可能还存在更多中枢震荡**（不一定像一、二之间那样紧接）。
     - **三买/三卖**: ① 次级别走势离开中枢（向上/向下）；② 第一次回试**不回到中枢区间**（买：低点不跌破 ZG；卖：高点不升破 ZD）；③ **结构段数至少 5 段次级别：前三段构成中枢、第四段离开、第五段构成第三类买卖点**（ch61）。
     - 三买核验五项必须逐项作答（缺一项即"信息不足"）：① 对应中枢已经确认；② 符合要求的次级别走势离开；③ 后续符合要求的次级别回试；④ 回试与 ZG/ZD 的关系（边界是否允许触及要写清）；⑤ **回试是否已完成**（依据是该次级别的背驰或双次回拉，见 E6）。**价格暂未回到中枢 ≠ 第三类买卖点已经确认。**

4. **位置 → 力度预判（二买/二卖专用，ch21）**
   - 完成标准: 给出二买/二卖相对中枢的位置及其后续倾向：
     | 二买出现位置 | 后续倾向 |
     |---|---|
     | 中枢之下 | 力度可疑，出现扩张性中枢的可能性极大 |
     | 中枢之中 | 中枢扩张与新生机会对半 |
     | 中枢之上 | 中枢新生的机会很大 |
   - 完成标准: 三买之后同步给出两种去向——**中枢扩张（更大级别中枢）** 或 **中枢新生（形成上涨趋势）**；并说明三买"后知后觉但省时间"的取舍。
   - 位置优劣（ch20 课后问答）: "第三类买点，一定要在**第一个中枢后**效果最好，如果在趋势的第 N 个中枢后，这样当然还是有利润，不过没必要了。"给出该三买是第几个中枢产生的第几段离开。

5. **重合判定（二、三类重合）**
   - 完成标准: 只有当"一买出现后一个次级别走势凌厉地上破前面下跌的最后一个中枢，然后在其上产生一个次级别的回抽不触及该中枢"时，才判二买与三买重合（卖点反向）。一买与二买、一买与三买**不可能重合**。

6. **列出成立条件与确认信号**
   - 完成标准: 给出需要继续确认的结构条件。三买的确认按原文口径（ch20 课后问答）：
     - "第三类买点一定要等到**次次级别的背驰或双次回拉**确认！因为这种刚上 0 轴的，根本就谈不上背驰，背驰是要上 0 轴后有一次大拉升，然后回抽 0 轴，再拉升，才会有背驰的。"
     - "第三类买点还是要**按第一类买点的来操作，只是看次级别以下的走势**。"
     - 三角形变体: "有三角形 5 段回拉的，只要**最后一次回拉不回到原来的中枢**就可以了"；对三角形只在高低位来回操作，"一旦过上沿没有背驰，就是真突破了"。

7. **列出失效条件**
   - 完成标准: 至少给出：跌回/升回中枢区间；破坏次级别结构（如回抽段延伸成新中枢）；出现前一买卖点被更低级别背驰证伪；数据不足。

8. **多义性复核（可选但推荐）**
   - 完成标准: 换一种合法分解重算一次，若买卖点位置一致 → 该点客观；若不一致 → 判"走势未完成，等信号"（见 `chanlun-duoyixing-jiehelv`）。

## B — 边界

- 不输出"现在买入/卖出"。
- 不在没有中枢和级别信息时硬判买卖点。
- 不把第三类买点后续必然趋势化；它也可能演化为更大级别盘整（原文："第三类买卖点后，并不必然是趋势，也有进入更大级别盘整的可能"）。
- 不参与中枢震荡时仍给中枢内买卖点：原文明确"第二、三买卖点之间都是中枢震荡，这时候，是不会有该级别的买卖点的"，参与只能降级到次级别买卖点。
- 不承诺盈利：原文说三买后"必然要赢利"是结构意义上的结论，不含滑点、涨跌停、流动性约束。

### 失败模式

- 把普通回踩当成三买（未核对 5 段结构、未核对是否第一次回试）。
- 把任何指标背离当成一买（未核对该级别是否为趋势、最后一段是否创新高/新低）。
- 用"第一次回调"当作二买的全部条件，漏掉"不创新高/盘整背驰"确认。
- 二买落在中枢之下却按中枢之上给预期。
- 上涨趋势里还在找一买、二买。
- 用加宽后的中枢区间（所有段重叠）去判三买，导致提前触发。

### 盲点 / 时代局限

- 实盘成交、仓位、滑点和止损不在原始结构规则内，需要交易系统另行处理。
- 不同交易品种的涨跌停、流动性会改变可执行性。
- 三买确认依赖"回抽次级别的第一类买卖点"，在极高流动性/跳空市场中该次级别背驰可能缺席（转到 `chanlun-small-to-large`）。
