# 缠论区间套定位

## R — 来源

依据《教你炒股票61：区间套定位标准图解（分析示范六）》《53：三类买卖点的再分辨》《102：再说走势必完美》。本 skill 是本地理论目录相对 book2skill 的**第二个全新补齐点**。

## I — 方法论骨架

区间套的目的：把"某级别疑似背驰"收缩成一个**当下可操作的精确点**。

三条底层规则：

1. **逐重下探**（ch61）：要与走势比较力度，先明确"哪两段比较"；围绕同一个中枢的两段走势都可以比较。对尚未走完的一段，**先假设它是背驰段**；一旦实际走出的力度大于前段，就可以断定背驰段不成立，背驰不会出现。**在没有证据否定背驰之前，就要观察该段内部结构中的背驰情况**，如此逐次下去——这就是区间套的定位方法，可以在当下精确定位转折点。
2. **不创新高/新低不存在背驰**（ch61）：例如 69 点不构成任何背驰，因为背驰如果没有创新高，是不存在的。
3. **显微镜纪律**（ch53）：用一个级别观察时，就等于先把其次级别当成没有内部结构的线段。要看次级别内部（例如判断 30 分钟三买需要看 5 分钟回抽），必须显式切换显微镜倍数；区间套与这条纪律不冲突——"只要知道该在什么时候用什么倍数的去看就可以"。

**重要限制（ch53）**：最严格的方法是从最低级别的分笔逐步组合上来，那样不存在上面的问题，"但这样太累，而且毫无必要"。区间套的层数不是越多越好，够用即止。

**为什么区间套成立（ch102）**：区间套是"走势必完美"（唯一分解定理）的应用——"如果市场走势没有本ID 所揭示的整体结构，那么区间套是不会存在，也就是没有操作意义的……有了区间套，买卖点的精确定位才有可能"。原文并给出级别的实用口径：从 1 分钟到年对应 8 个级别，"这些级别的名字是可以随意取的"，而"一般来说，1、5、30 分钟三个级别的分解，就足以应付所有的走势"——这也是区间套下探层数的实践上限参考。

## A1 — 书中的应用

### 案例：72 点的四重背驰定位（ch61，2007-06-20 大盘）
- **问题**: 1 分钟顶背驰有时跌幅大、有时很小，究竟何时该走。
- **方法论的使用**: 55–60 与 65 起始段围绕 60–65 这个 1 分钟中枢比较 → 先假设 65 起始段为背驰段；69 点不构成背驰（未创新高）；70 点进入真正背驰危险区但 69–70 与 67–68 无盘整背驰；71 点是对 66–69 中枢的第三类买点，而 71 起始的向上段力度明显弱于 69–70 段（MACD 红柱面积和可辅助判断）→ 于是 65 起始是第一重、69 起始是第二重、71 起始是第三重、71 内部背驰是第四重。
- **结论**: 72 点这个背驰点由"背驰段的背驰段的背驰段的背驰段"构成，构成一个区间套的精确定位，且"这一切，都可以当下地进行"。
- **结果**: 定位精度来自逐重下探，而不是更强的预测。同时 74 点给出第二类卖点 = 69–72 中枢的第三类卖点（重合，需满足结合律）。

## A2 — 触发场景

1. 用户给出多周期数据，问"精确的转折点在哪"。
2. 用户说"大级别背驰但我不知道具体在哪里动手"。
3. 用户问"这里算不算背驰段成立"。
4. 用户已经用 `chanlun-divergence-diagnosis` 得到"疑似背驰"，需要收敛到点位。

### 语言信号

- "区间套"
- "精确定位买卖点"
- "背驰段的背驰段"
- "这里是第几重背驰"

### 与相邻 skill 的区分

- 与 `chanlun-divergence-diagnosis`: 它给"是不是背驰、哪一段"，本 skill 给"在哪一点、还差几重"。
- 与 `chanlun-buy-sell-points`: 它给候选类型，本 skill 把候选收敛为一个点位。
- 与 `chanlun-multi-level-scenario`: 本 skill 管点位精度，它管背驰后的情景树。

## E — 可执行步骤

1. **声明操作级别与显微镜倍数**
   - 完成标准: 明确主级别（如 30 分钟）与将要切入的次级别序列（如 5 分钟 → 1 分钟），并说明"当前级别观察时次级别视为线段"。

2. **确定比较对**
   - 完成标准: 明确"哪两段比较"：围绕同一中枢的两段（A 与 C），或围绕次级别中枢的两段；给出两段的起止与方向。
   - 判停条件: 无法指出比较对（结构未标注）→ 停止，先过 `chanlun-structure-parser` / `chanlun-zhongshu-mapper`。

3. **假设背驰段并设否决条件**
   - 完成标准: 写出"假设 C 为背驰段"以及**否决条件**（一旦 C 段力度大于 A 段即否定背驰段）。这样才有"没有证据否定就继续下探"的合法性。

4. **过前置条件**
   - 完成标准: 确认 C 段已创新高/新低（否则背驰不存在，直接终止）；确认 A、C 同级别；确认 MACD/面积等辅助证据。

5. **逐重下探**
   - 完成标准: 对当前背驰段的内部结构重复第 2–4 步，记录层数：第 1 重 → 第 2 重 → … 每重注明"该重内部的比较对 + 是否出现内部背驰"。
   - 完成标准: 层数**够用即止**：出现内部背驰即可定位，不必逐级下探到分笔。

6. **输出定位结果**
   - 完成标准: 输出"精确定位点 + 层数 + 该点是哪个次级别中枢的第几类买卖点"。
   - 校验: 用 `chanlun-duoyixing-jiehelv` 换一种分解复核点位是否一致。

7. **给出失守与推翻条件**
   - 完成标准: 明确什么走势会推翻"背驰段"假设（力度超越前段）、什么会推翻定位点（跌破/升破关键中枢边界）。

## B — 边界

- 不预测未来点位；区间套只处理"当下已走出的结构"。
- **不能承诺定位到未来的绝对最低点或最高点**；能定位的是"当下已知结构下的转折点"，其确认时刻永远晚于极值时刻（见 V 段时间双轨）。
- 不在单一时间周期图上做区间套（至少需要两个相邻级别）。
- 不承诺点位绝对精确：原文的口径是"当下可以精确定位转折点"，前提是级别与结构标注正确。
- 不逐级下探到分笔（原文明确"太累，而且毫无必要"）。

### 失败模式

- 跳过"假设背驰段 + 否决条件"，直接宣布某点是转折。
- 在 C 段未创新高/新低时开始下探，白做工。
- 跨级别比较力度（用 1 分钟段与 5 分钟段直接比大小）。
- 只看 MACD 面积不看结构，把区间套退化成指标嵌套。
- 层数无上限地递归，输出噪声而非信号。

### 盲点 / 时代局限

- 原文案例基于 2007 年 T+1、涨跌停市场的分钟走势；其他市场与品种的次级别结构可能不连续，层数会失去意义。
- 当下未完成走势的最后一重背驰永远不能在当下"确认"，只能按假设处理（这是区间套的固有代价）。
- 大资金无法在小级别点位全仓进出，定位精度与可执行性不匹配（原文：大级别操作者可据 5 分钟震荡容量做对冲）。
