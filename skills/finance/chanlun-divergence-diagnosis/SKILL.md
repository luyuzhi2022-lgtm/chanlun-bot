# 缠论背驰诊断

## R — 来源

依据《教你炒股票15：没有趋势，没有背驰》《24：MACD 对背弛的辅助判断》《25：吻，MACD、背弛、中枢》《27：盘整背驰与历史性底部》《29：转折的力度与级别》《37：背驰的再分辨》《43：有关背驰的补习课》《53：三类买卖点的再分辨》《61：区间套定位标准图解》。

## I — 方法论骨架

背驰不是"指标背离"四个字那么简单。标准背驰需要在同一分析级别下，识别 A-B-C 三段结构。

**三条硬前提（缺一条即不能判背驰）**：
1. **没有趋势，没有背驰**（ch15）：先确认这是趋势/盘整，再谈背驰；趋势背驰与盘整背驰是两个不同工具。
2. **不创新高/新低，不存在背驰**（ch61）：离开段必须先创新高（顶背驰）或新低（底背驰），否则无背驰可言。
3. **同级别比较**：A 段与 C 段必须同级别；跨级别比较无效。

B 段通常对应一个中枢，并使 MACD 黄白线回拉到 0 轴附近。C 段与 A 段同向而力度弱于 A 段，才构成候选背驰。**MACD 只是辅助**（ch24 标题即"辅助判断"），面积/高度比较是证据之一，不是判据本身。

背驰只说明某级别趋势力量衰竭；之后可能是弱反弹、中枢扩张、更大级别盘整或反趋势（→ `chanlun-multi-level-scenario`）。

**背驰-买卖点定理（ch17/21）**：任一背驰都必然制造某级别的买卖点；任一级别的买卖点都必然源自某级别走势的背驰。

## A1 — 书中的应用

### 案例一：用 MACD 辅助判断 A-B-C 段（ch24）
- **问题**: 用户难以直接从中枢结构判断背驰。
- **方法论的使用**: 先划分 A-B-C，再比较 C 段与 A 段的 MACD 柱面积和力度。
- **结论**: MACD 可作为辅助，但不能替代中枢和级别。
- **结果**: 背驰判断从单指标感觉转成结构化检查。

### 案例二：区间套下的四重背驰（ch61，65→72 点）
- **问题**: 1 分钟顶背驰为什么有时跌幅大、有时很小。
- **方法论的使用**: 先假设 65 开始的一段为背驰段，再逐次看其内部结构，依次得到第二重、第三重、第四重背驰段，72 点由"背驰段的背驰段的背驰段的背驰段"构成。
- **结论**: 定位精度靠逐重下探，不靠单次比较。
- **结果**: 转折点可"当下精确定位"（详见 `chanlun-qujian-tao`）。

## A2 — 触发场景

1. 用户问"这里是不是背驰/背离"。
2. 用户给出 A-B-C 段，希望判断 C 段力度是否弱。
3. 用户想知道背驰后可能是什么级别的转折。
4. 用户问"1 分钟背驰了，大级别会转吗"（转 `chanlun-small-to-large`）。

### 语言信号

- "是不是顶背驰" / "MACD红柱变短"
- "C段比A段弱吗"
- "背驰后会怎么走"
- "盘整背驰还是趋势背驰"

### 与相邻 skill 的区分

- 与 `chanlun-buy-sell-points`: 本 skill 判断背驰条件；买卖点类型另行判断。
- 与 `chanlun-qujian-tao`: 本 skill 给"是不是背驰"，区间套负责把它收缩到一个精确点位。
- 与 `chanlun-small-to-large`: 背驰级别 < 当下走势级别时，必须转该 skill，本 skill 不单独下结论。

## E — 可执行步骤

1. **确认级别和 A-B-C 段**
   - 完成标准: 明确 A、B、C 的起止和方向。
   - 判停条件: A-B-C 不清晰，或未确认笔/线段结构 → 要求先调用 `chanlun-structure-parser` / `chanlun-zhongshu-mapper`。

2. **过三前提**
   - 完成标准: 逐条作答：① 这是趋势还是盘整（决定用趋势背驰还是盘整背驰）？② 离开段是否创新高/新低？③ A 与 C 是否同级别？任一条不满足 → 判"背驰不成立"，不再继续。

3. **检查 B 段中枢作用**
   - 完成标准: 判断 B 段是否承担连接、回拉或中枢功能（MACD 黄白线是否回到 0 轴附近）。
   - 顺序铁律: **先确定比较对象 → 再确认可比性 → 最后使用指标辅助**；顺序颠倒即视为无效分析。
   - 检查清单: 比较段与哪个中枢相关、方向与级别、是否创新高/新低、趋势背驰还是盘整背驰、**比较段是否已完成**、是否存在继续延伸的可能。
   - 使用 MACD 时必须声明: 参数与图表周期、柱体面积的计算区间、黄白线与零轴关系、缺失数据与初始化影响。**未完成段的累计面积暂时较小，不足以确认背驰**；**柱体颜色不作统一标准，应以数值正负为准**；MACD 只提供辅助证据。

4. **比较 A 与 C 的力度**
   - 完成标准: 从价格推进、斜率、成交量、MACD 柱面积等角度比较；说明用的是哪几项证据。
   - 技巧（原文）: 面积不必等走完，柱子伸长力度变慢时把已出现面积乘 2 估算总面积；急促走势可用红柱伸长高度的"两次/三次冲击同一高度不能突破"作为辅助。

5. **分类输出**
   - 完成标准: 输出"标准趋势背驰 / 盘整背驰 / 不成立 / 数据不足"之一，并写明级别。
   - 盘整背驰要点（ch53）: a+B+c 中，a 与 c 的盘整背驰都可看成 B 的中枢震荡的力度比较——即使 a 出现时 B 尚未形成。

6. **标注背驰级别与当下走势级别的关系**
   - 完成标准: 明确"背驰级别 = 当下走势级别"（可按本级别力度直接处理）还是"背驰级别 < 当下走势级别"（小转大，转 `chanlun-small-to-large`，并给必要条件而非结论）。

7. **输出后续情景**
   - 完成标准: 至少列出弱反弹/弱回落、级别扩张或更大级别中枢、反趋势三类可能及确认信号（→ `chanlun-multi-level-scenario`）。

## B — 边界

- 不要仅凭 MACD 柱缩短就断定背驰（前后两次同高、柱面积、结构三者至少两项）。
- 不要跨级别比较 A 与 C。
- 不要把背驰等同于马上大反转。
- 不要在未创新高/新低时判背驰。
- 不要把背驰诊断的结论放大到更高级别（背驰级别与操作级别必须对齐；1 分钟顶背驰对月线操作者无意义）。

### 失败模式

- 先有主观看多/看空，再强行寻找背驰。
- 忽略 B 段中枢，只比较两个指标峰值。
- 把小级别背驰当作大级别转折。
- 用"背离"（红绿柱高度比较）冒充"背驰"（面积 + 结构比较）。
- 在盘整里套用趋势背驰的力度标准。

### 盲点 / 时代局限

- MACD 参数、交易品种、波动结构不同，会影响辅助判断。
- 高频、跳空、涨跌停市场中，指标面积比较可能失真。
- 动力学部分以"价格充分有效市场 + 非完全绝对趋同交易"为前提；庄股、极低流动性品种该前提不成立。
