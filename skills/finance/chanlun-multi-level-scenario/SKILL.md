# 缠论多级别情景推演

## R — 来源

依据《教你炒股票20：走势中枢级别扩张及第三类买卖点》《29：转折的力度与级别》《44：小级别背驰引发大级别转折》《73：市场获利机会的绝对分类》《89：中阴阶段的具体分析》《90：中阴阶段结束时间的辅助判断》。

> **v2 相对原版的差别**：原版只覆盖 ch20/29 的三情景；v2 加上 ch73 的**上位二分类框架**（所有获利机会只有"中枢上移/中枢震荡"两种）、ch44 的**分流判定**（背驰级别 < 走势级别时必须转 `chanlun-small-to-large`）、ch89/90 的**中阴情景**。

## I — 方法论骨架

缠论最容易被误用的地方，是把小级别信号直接放大成大级别结论。

**先做上位分类（ch73，天然的二分类）**：任何市场的获利机会，在本理论下"只有两种：**中枢上移**与**中枢震荡**"。
- **中枢上移**（= 该级别的上涨走势）："是不存在着任何理论上短差机会的，除非这种上移结束进入新中枢的形成与震荡。"
- **中枢震荡**（= 该级别的盘整，或上涨中新中枢形成后的延续过程）："就是短差的理论天堂。只要在任何的中枢震荡向上的离开段卖点区域走掉，必然有机会在其后的中枢震荡中回补回来，唯一需要一定技术要求的，就是对第三类买点的判断。"
- 纵向视角（原文）："用同一级别的视角去看走势，就如同用一个横切面去考察"，把不同级别纵向比较才有纵向视野；月线级别的上涨，在年线级别上可能只是"一个中枢震荡中的一个小段"。

**再做情景推演**：某级别背驰后，不只有"反转"一种结果。常见情景：只触及最后中枢附近的弱反弹/弱回落、形成更大级别中枢、进入同级别或更高级别反趋势。多级别推演的目标是**提前列出条件，而不是提前押注答案**。合格输出必须同时写出成立条件、失效条件和下一步观察点。

**中阴情景（ch89/90）**：某级别走势结束后进入中阴阶段，"虽然表现为中枢震荡，但并不是一般性的中枢震荡"；其中 100% 可操作的锚点是"必须先出现一个更高级别中枢"。结束时间用 BOLL 收口辅助（详见 `chanlun-zhongyin-stage`）。

## V — 证据与版本治理（横切，10 个缠论技能共用同一口径）

1. **来源分层**：引用条文时标注来源等级——【课程正文】/【作者答疑】/【编者或读者说明】/【分析推论】/【工程约定】/【待核验】。**编者或读者批注不得升级为作者定义**；附件中的署名与编排不自动视为已鉴真。
2. **更正链优先**：早期教学简化 < 后续严格定义 < 后续更正。已知更正链（线段）：ch62/65（早期）→ **ch67（特征序列标准）** → ch71/77/78（补充）→ **ch81 更正 ch71 末图**。后文明确更正优先于被更正内容；无法消解的分歧要列出冲突与采用口径，不自行伪造统一结论。
3. **时间双轨**：任何结构或信号记录两个时刻——**端点时间**（极值/端点所在时间）与**确认时间**（最早能被确认的时间）。K 线未收盘、或右侧条件尚未满足时，只能标"候选"，不得把后来形成的极值回填成当时已知的信号。
4. **状态用词统一**：`候选 / 已确认 / 已失效 / 信息不足` 四选一，不得把候选当确认。
5. **数据核验前置**：核对 OHLC 合法性、复权一致性、停牌与缺 K、最后一根 K 线是否收盘、图形或数据是否被截断或来源不一。缺关键字段时**不输出精确结构**，只做定性判断。
6. **原文主张 ≠ 现实保证**：原文的"绝对安全""必然获利""零成本无风险"标注为**作者的理论或操作主张**；T+1、涨跌停、滑点、手续费、成交容量、流动性与停牌退市风险不在结构规则内，需另行处理。

## A1 — 书中的应用

### 案例：5 分钟下跌背驰后的三类结果（ch20/29）
- **问题**: 5 分钟级别下跌背驰后，反弹到底意味着什么。
- **方法论的使用**: 把后续分为最后中枢扩展、更大级别盘整、反趋势等情景。
- **结论**: 背驰后要看反弹是否回到最后中枢以及后续结构。
- **结果**: 避免一看到背驰就断言大反转。

### 案例二：年线/季线视角下的"大机会"（ch73）
- **问题**: 同一段上涨，在小级别是主升，在大级别只是震荡的一段。
- **方法论的使用**: 纵向比较级别：一个年中枢的上移构成人生可能参与的最大投资机会；对大多数人最现实的是一个季度甚至月线级别中枢上移。
- **结论**: 先确定自己在找哪一级别的"中枢上移"，再谈买卖点。
- **结果**: 情景推演不会越级——不会用 5 分钟信号去回答年线问题。

## A2 — 触发场景

1. 用户说大级别和小级别信号冲突。
2. 用户问背驰后是反弹、盘整还是反转。
3. 用户要求做"如果 A 则 B，如果失败则 C"的预案。
4. 用户问"这波是中枢上移还是中枢震荡"（ch73 上位分类）。

### 语言信号

- "日线还没走完，但30分钟背驰"
- "这只是反弹还是反转"
- "多级别怎么看"
- "给我三种情景预案"
- "是中枢上移还是中枢震荡"

### 与相邻 skill 的区分

- 与 `chanlun-divergence-diagnosis`: 背驰诊断只回答是否背驰；本 skill 处理背驰后的多级别演化。
- 与 `chanlun-buy-sell-points`: 本 skill 输出情景树，不判断单个买卖点是否成立。
- 与 `chanlun-small-to-large`: 当"背驰级别 < 当下走势级别"时，本 skill 必须**分流**给该 skill 处理，不得自行给结论。
- 与 `chanlun-zhongyin-stage`: 当走势已结束、进入过渡期时，中阴处理由该 skill 负责。

## E — 可执行步骤

1. **列出所有相关级别**
   - 完成标准: 至少区分大级别、操作级别、次级别，并说明各自的中枢位置。

2. **上位二分类：中枢上移 or 中枢震荡（ch73）**
   - 完成标准: 输出当前处于"中枢上移"还是"中枢震荡"；若中枢上移则说明"理论上不存在短差机会"（除非进入新中枢形成与震荡）；若中枢震荡则说明"短差窗口在向上离开段的卖点区域，回补靠第三类买点判断"。

3. **锁定上一级中枢和最后中枢**
   - 完成标准: 明确观察"是否回到/离开/跌回中枢"的关键位置（用原文口径的 [ZD, ZG]）。

4. **分流判定：背驰级别 vs 当下走势级别**
   - 完成标准: 若背驰级别 = 当下走势级别 → 按本级别情景推演；若背驰级别 < 当下走势级别 → **转 `chanlun-small-to-large`**，本 skill 不直接给情景。

5. **生成三种情景**
   - 完成标准:
     - 弱反弹/弱回落（只触及最后中枢附近）。
     - 更大级别中枢或盘整（中枢扩张/中枢震荡延伸）。
     - 反趋势（同级别或更高级别）。
   - 附加项: 若走势已结束正在过渡 → 增列**中阴情景**（必先出现更高级别中枢）。

6. **为每种情景列确认信号**
   - 完成标准: 每个情景至少 2 个结构确认条件（如是否回到最后中枢、是否出现第三类买卖点、次级别是否出现背驰、Zn 是否超越 A/B、BOLL 是否收口）。

7. **给出下一步数据需求**
   - 完成标准: 明确下一根/下一段/下一中枢要观察什么；注明需要哪个级别的数据。

## B — 边界

- 不承诺哪种情景一定发生。
- **没有统计依据就不提供伪精确概率**；"**证据不足，继续观察**"是有效结论，不是失败。
- 输出情景表固定用三列：**触发条件 / 观察事项 / 失效条件**。
- 不把小级别背驰直接当成大级别反转。
- 不在没有级别信息时做多级别推演。
- 不用单一结论替代情景树。
- 不在中枢上移阶段承诺短差收益（原文明确理论上不存在）。

### 失败模式

- 用单一结论替代情景树。
- 忽略最后一个中枢的位置。
- 只写看多/看空，不写失效条件。
- 越级推演：用 5 分钟情景回答"年线机会"这类问题，或把月线上涨在小级别上切成无数次"反转"。
- 忘记 ch73 上位分类，把中枢上移中的正常震荡当短差天堂，反复被甩。
- 把中阴阶段的震荡当作普通中枢震荡来推演方向。

### 盲点 / 时代局限

- 多级别推演容易变复杂，必须控制输出为可操作的三种情景。
- 对真实交易还需叠加仓位、止损、市场流动性和交易成本。
- ch73 的大级别中枢上移判断需要基本面与比价关系两个独立系统的配合（原文：技术面、基本面、比价关系三系统组合），本 skill 只覆盖技术面部分。
