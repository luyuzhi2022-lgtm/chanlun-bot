# 缠论走势多义性与结合律校验

## R — 来源

依据《教你炒股票33：走势的多义性》《36：走势类型连接结合性的简单运用》《38：走势类型连接的同级别分解》《39：同级别分解再研究》《40：同级别分解的多重赋格》《61：区间套定位标准图解》《73：市场获利机会的绝对分类》。本 skill 是本地理论目录相对 book2skill 的**第五个全新补齐点**，也是其他所有技能之上的校验层。

## I — 方法论骨架

**结合律**：走势组件在满足结合律的前提下可以多种拆分与组合：a + b + c = (a + b) + c = a + (b + c)。任何一段走势都可以有很多种释义。

**买卖点变换不变性**：不同的组合可以得出不同的走势定义，但**买卖点是变换不变的**。通过对同一走势的不同拆分、组合，去看最后的买卖点是否发生改变，**如果得出了一个相同的结果，这个结果才是客观保证的**。

**多义性的第二重用途**：它也是对可能走势的一种枚举分类，可以为后续行情做多手预案（与 `chanlun-multi-level-scenario` 的情景树天然衔接）。

**消除多义性的原文手段（ch33）**：多义性"都与中枢有关"，例如 5 分钟中枢不断延伸、出现 9 段以上的 1 分钟次级别走势时，既可读作 5 分钟中枢延伸，也可解释为 30 分钟中枢。原文给出的解决办法是**限制中枢延伸的数量**——"一般来说，中枢的延伸不能超过 5 段，也就是一旦出现 6 段的延伸，加上形成中枢本身那三段，就构成更大级别的中枢了"。另一类多义性来自"模本的简略"（不同级别的图是对真实走势不同精度的模本）。

**同级别分解**：把任意走势分解成同级别走势类型的连接（ch38/39/40）。操作上只看该级别买卖点，不考虑更高级别或更低级别——"思维简单，节奏清晰"。原文用"多重赋格"比喻同级别分解的叠加运用。

**必须满足结合律的实例（ch61）**：74 点既是第二类卖点又是第三类卖点，但它的中枢归属必须满足结合律——"显然不是 70–73 这个，因为这里需要满足结合律"，正确答案是 69–72 这个中枢的三卖。这说明**点的性质会因分解方式而变，但点本身的位置不变**。

## V — 证据与版本治理（横切，10 个缠论技能共用同一口径）

1. **来源分层**：引用条文时标注来源等级——【课程正文】/【作者答疑】/【编者或读者说明】/【分析推论】/【工程约定】/【待核验】。**编者或读者批注不得升级为作者定义**；附件中的署名与编排不自动视为已鉴真。
2. **更正链优先**：早期教学简化 < 后续严格定义 < 后续更正。已知更正链（线段）：ch62/65（早期）→ **ch67（特征序列标准）** → ch71/77/78（补充）→ **ch81 更正 ch71 末图**。后文明确更正优先于被更正内容；无法消解的分歧要列出冲突与采用口径，不自行伪造统一结论。
3. **时间双轨**：任何结构或信号记录两个时刻——**端点时间**（极值/端点所在时间）与**确认时间**（最早能被确认的时间）。K 线未收盘、或右侧条件尚未满足时，只能标"候选"，不得把后来形成的极值回填成当时已知的信号。
4. **状态用词统一**：`候选 / 已确认 / 已失效 / 信息不足` 四选一，不得把候选当确认。
5. **数据核验前置**：核对 OHLC 合法性、复权一致性、停牌与缺 K、最后一根 K 线是否收盘、图形或数据是否被截断或来源不一。缺关键字段时**不输出精确结构**，只做定性判断。
6. **原文主张 ≠ 现实保证**：原文的"绝对安全""必然获利""零成本无风险"标注为**作者的理论或操作主张**；T+1、涨跌停、滑点、手续费、成交容量、流动性与停牌退市风险不在结构规则内，需另行处理。

## A1 — 书中的应用

### 案例：74 点的归属之争（ch61）
- **问题**: 同一个 74 点，是二卖还是三卖？属于哪个中枢？
- **方法论的使用**: 分别在"65 起始走势的级别"与"1 分钟中枢级别"两种分解下检查；前者给出第二类卖点，后者给出第三类卖点，且要求中枢归属满足结合律。
- **结论**: 两种分解都指向 74 这同一个点位 → 该点客观；性质上是"二、三类重合"，原文提示其后力度值得关注（实际其后出现更大力度的下跌）。
- **结果**: 校验流程（换分解 → 看点位是否一致）比争论"它到底叫什么"更有价值。

## A2 — 触发场景

1. 用户问"这里到底算一笔/一段/一个中枢吗，换个划分是不是就不一样了"。
2. 用户对某个买卖点结论不确定，要求复核。
3. 用户想按同级别分解建立操作节奏。
4. 用户问"走势还没走完怎么判断"。

### 语言信号

- "多义性" / "结合律"
- "换个划法是不是就不一样了"
- "这个点可靠吗"
- "同级别分解"

### 与相邻 skill 的区分

- 与 `chanlun-buy-sell-points`: 它给类型，本 skill 给"该结论是否经得起重新分解"。
- 与 `chanlun-multi-level-scenario`: 本 skill 枚举分解方式，它枚举后续情景。
- 与 `chanlun-structure-parser`: 它给一种划分，本 skill 要求第二种划分做交叉。

## E — 可执行步骤

1. **固定待校验结论**
   - 完成标准: 写下待校验的命题，形如"X 点是某级别第 N 类买卖点，归属中枢 C"。
   - 口径纪律: **同一任务中保持口径一致**（周期、价格精度、相等值处理、包含关系处理方式、笔/线段规则版本、最小分析单位）；**不得为配合买卖结论临时切换规则**。
   - 判停条件: 若无明确命题（只是泛泛看多/看空）→ 转 `chanlun-buy-sell-points`。

2. **给出第一分解**
   - 完成标准: 标注级别、笔/线段、中枢区间与归属走势段（用原文口径的 [ZD, ZG]）。

3. **构造第二种合法分解**
   - 完成标准: 用结合律重组（例如把中枢归属从 70–73 改为 69–72，或把某段并入/拆出前一笔线段），并说明该分解合法性的依据。
   - 完成标准: 至少给出 2 种分解；每种都写明"为什么合法"（不能为了得到想要的结果而随意重组）。

4. **比较买卖点位置**
   - 完成标准: 输出两种分解下的买卖点位置，逐项比较：
     - **位置一致** → 该买卖点客观可靠，给出"高置信度"结论。
     - **位置不一致** → 判"走势尚未走完/分解依赖未完成结构"，输出"需等待更明确的信号"，并列出等待什么（哪一段完成、哪个中枢成型、哪个次级别买卖点出现）。
   - 完成标准: 明确"点的位置"优先于"点的名称"；名称（一/二/三类）可以随分解改变，位置改变才说明结论不成立。

5. **输出多手预案（可选）**
   - 完成标准: 对可能走势做枚举分类，为每种情况给出一条应对条件；与 `chanlun-multi-level-scenario` 对接。

6. **同级别分解视角复核**
   - 完成标准: 把走势拆成同级别走势类型的连接，检查买卖点是否落在该级别的连接点上；若买卖点落在更小级别内部 → 说明"该点不属于当前操作级别"，不应作为本级别操作依据。

## B — 边界

- 不给唯一正确答案：多义性是理论的内置性质，不是缺陷。
- 不为了得到目标结论而构造分解（"事后重画结构来配合结论"是原文级反模式）。
- 不在结构未标注时谈多义性。
- 不把"两种分解结果不同"当作分析方法失败；它本身就是"走势未完成"的信息。

### 失败模式

- 只给一种分解就宣布结论，不做交叉。
- 分组时违反结合律（把 a+b 拆成跨越 a 与 b 的不连续组合）。
- 把"名称变化"误判为"结论变化"（如二卖/三卖重合被当成矛盾）。
- 用多义性当借口拖延，永远不给结论（应给出"等待什么信号"的可操作出口）。
- 在同级别分解中混入次级别买卖点，导致级别错位。

### 盲点 / 时代局限

- 原文的多义性讨论以手工标注为前提；自动化程序对不同分解的枚举能力有限。
- "买卖点变换不变性"是理论宣称，原文未给出穷举证明，实践中依赖标注者的合法分解集合是否正确。
- 对未完成的最后一笔/段，多义性无法消除，只能等待（这是理论的结构性边界）。
