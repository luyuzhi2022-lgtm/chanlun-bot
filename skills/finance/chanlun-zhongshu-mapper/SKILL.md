# 缠论中枢定位

## R — 来源

依据《教你炒股票17：走势终完美》《20：走势中枢级别扩张及第三类买卖点》《21：买卖点分析的完备性》《92：中枢震荡的监视器》。

## I — 方法论骨架

中枢是缠论判断走势类型的核心。判断不靠主观感觉，而看次级别走势之间是否形成重叠区间。

**原文口径（ch20，务必按此计算）**：
- 中枢由**前三个连续次级别走势类型**的重叠部分确定。
- 与中枢方向一致的次级别走势类型称为 **Z 走势段**，按时间顺序记为 Zn，其高低点记为 gn、dn。
- **ZG = min(g1, g2)，ZD = max(d1, d2)** → [ZD, ZG] 就是中枢区间，**由前两个 Z 段（即前三段）锁定**。
- GG = max(gn)、G = min(gn)、D = max(dn)、DD = min(dn)，这些才"n 遍历中枢中所有 Zn"。
- 记忆要点：中枢区间 [ZD, ZG] 成立即锁定；随走势越走越宽的是 GG/DD，不是 ZG/ZD。

## A1 — 书中的应用

### 案例：日线与 30 分钟级别差异
- **问题**: 类似图形为什么有的算日线级别走势，有的只算 30 分钟级别走势。
- **方法论的使用**: 通过是否在对应级别形成中枢来区分。
- **结论**: 走势级别由中枢结构决定，不由肉眼相似度决定。
- **结果**: 避免把小级别走势误判成大级别趋势。

## A2 — 触发场景

1. 用户问"这里是中枢延伸还是新中枢"。
2. 用户给出几段次级别走势，要求计算中枢区间。
3. 用户想判断当下是盘整、趋势还是级别扩张。
4. 用户问"这个中枢震荡在走强还是走弱"（转 `chanlun-zhongshu-oscillation`）。

### 语言信号

- "中枢区间是多少"
- "这是中枢扩张吗" / "有没有形成更大级别中枢"
- "这里还是趋势吗"
- "中枢延伸还是新生"

### 与相邻 skill 的区分

- 与 `chanlun-structure-parser`: 本 skill 假设已有笔/线段或次级别走势。
- 与 `chanlun-buy-sell-points`: 本 skill 判断地图与地图状态，不判断买卖点。
- 与 `chanlun-zhongshu-oscillation`: 本 skill 给中枢边界，Zn 监视器量化震荡强弱。

## E — 可执行步骤

1. **确认分析级别与次级别**
   - 完成标准: 明确"当前级别"和构成它的"次级别走势"；声明观察级别即视次级别为线段（ch53）。

2. **列出连续三段次级别走势**
   - 完成标准: 至少有三段可比较区间；不足则**停止**并要求补充数据。

3. **计算中枢区间（原文口径）**
   - 完成标准: 给出 ZG = min(g1, g2)、ZD = max(d1, d2) 与区间 [ZD, ZG]，并说明计算依据。
   - 完成标准: 若需要波动极值，另给 GG / DD / G / D（遍历所有 Zn）。
   - 禁止: 用"所有 Z 段重叠"去改中枢区间（那是实战变体，会让三买定理的基准漂移）。

4. **判断中枢状态（原文三态：延续 / 扩张 / 新生）**
   - 完成标准: 中枢记录须包含六项——**级别 / 构成区间 / ZD、ZG / 所用构件 / 最早确认时间 / 状态（延续·扩张·新生·离开）**；并**区分中枢核心区间与外围波动区间**（[ZD,ZG] 是核心区间，GG/DD 是外围波动）。
   - 边界口径: 仅在一个价格点接触时，按预先声明的口径处理；同一任务内口径保持一致。
   - 完成标准: 结合中枢中心定理输出其一：
     - **延续**：任意区间 [dn, gn] 与 [ZD, ZG] 有重叠（等价于所有围绕中枢的前后两个次级波动至少有一个触及中枢区间）。
     - **扩张**：后 ZG < 前 ZD 且后 GG ≥ 前 DD，或后 ZD > 前 ZG 且后 DD ≤ 前 GG → 形成更大级别中枢。
     - **新生**：三个连续次级别走势的重叠区间离开原中枢 → 产生新的同级别中枢。
   - 完成标准: 前后两个同级别中枢若"后 GG < 前 DD"判为下跌及其延续，"后 DD > 前 GG"判为上涨及其延续。
   - 注意: 趋势要求同级别前后中枢**任何瞬间波动都不重叠**；只要围绕新中枢的波动触及前中枢延伸时的某个瞬间区间，就只是形成更大级别中枢，不是趋势。
   - **延伸段数上限（ch33）**: "一般来说，中枢的延伸**不能超过 5 段**，也就是一旦出现 6 段的延伸，加上形成中枢本身那三段，就构成更大级别的中枢了。"即 3+6=9 段即为级别升级（原文实例见 ch96："这里已经延伸 9 段，成为一个 5 分钟中枢了"）。超过 9 段的"中心点"分析已无意义。

5. **给出走势类型结论**
   - 完成标准: 输出"盘整 / 上涨趋势 / 下跌趋势 / 级别升级中 / 无法确认"之一；盘整 = 只含一个中枢，趋势 = 至少两个同向不重叠中枢。

6. **给出失效条件**
   - 完成标准: 明确什么价格行为会推翻当前中枢判断（例如出现 dn > ZG 或 gn < ZD 的 Zn → 必然产生高级别中枢或趋势）。

## B — 边界

### 概念边界（不得混淆）

- **三笔重叠不能自动称为任意级别的走势中枢**——中枢要求构件的级别符合定义，不是价格区间的几何交集。
- **走势中枢 ≠ 盘整走势类型**；盘整/趋势的判定须结合**完成状态、同级别中枢数量、方向与适用的不重叠条件**，不能只数矩形框。
- K 线时间周期（1 分钟/日线…）≠ 递归意义上的走势级别。
- 本 skill 只给"地图与地图状态"，不判断买卖点。

- 没有次级别走势段时不要硬算中枢。
- 不要把普通箱体震荡直接等同于缠论中枢。
- 不要把"突破中枢"自动当成买点，仍需看回试和级别。
- 不要在未完成笔/线段上加算中枢（"结构标注稳定，后续分析才有意义"）。
- 不要混用两种中枢区间取法：原文 ZG/ZD 锁定期与"所有段重叠"不能同时作为三买基准。

### 失败模式

- 只看价格区间，不看构成中枢的走势段。
- 混用不同级别的数据。
- 把中枢扩张误判为趋势延续（或反之）；原文对此的判据是"围绕中枢的波动是否触及前中枢延伸中的瞬间波动区间"。
- 用加宽后的中枢区间去判三买，导致三买提前触发。
- 忽略"两个中枢的波动是否重叠"就宣布趋势成立。

### 盲点 / 时代局限

- 低流动性和跳空较多的品种，次级别走势可能不连续。
- 当下未完成走势会影响中枢边界确认（原文提醒：新中枢形成前，"延续、扩展、新生"三种可能性在逻辑上都不能完全排除）。
- ZG/ZD 锁定期在实战中可能显得滞后，这是原文口径的代价，习惯"所有段重叠"的人需要显式切换。
