# 缠论中枢震荡监视器（Zn）

## R — 来源

依据《教你炒股票92：中枢震荡的监视器》（辅以《90：中阴阶段结束时间的辅助判断》的 BOLL 时间把握）。本 skill 是本地理论目录相对 book2skill 的**第三个全新补齐点**，也是三买的"提前预警器"。

## I — 方法论骨架

中枢震荡最终一定以某级别的第三类买卖点结束。问题在于**如何预先给出有参考价值的提示**——这震荡是在逐步走强还是逐步走弱。

原文工具：

- 中枢区间记为 [A, B]（A = 下沿 ZD，B = 上沿 ZG）。
- **震荡中轴 Z = (A+B)/2**；A、Z、B 三条线等距。
- 每个次级震荡区间的一半位置，依次记为 **Zn**。
- **Zn 在 Z 之上 = 震荡偏强；Zn 在 Z 之下 = 震荡偏弱。** Zn 的波动连成曲线，构成监视中枢震荡的技术指标。
- **必然关系**: 最终 Zn 肯定要超越 A 或 B——否则永远不会出现第三类买卖点。
- **但反过来不成立**: Zn 超越 A 或 B 并不意味着一定出现第三类买卖点；这种超越可以多次，**只有最后一次才构成第三类买卖点**。
- **数量上限**: Zn 不超过 9 个数据；超过 9 个，次级别就要升级了，此时该分析已无意义。
- **扩展概率**: 若某次超越没有构成第三类买卖点，**一般都将构成中枢震荡级别的扩展**（非 100%，但概率极高）。

**实战含义（原文）**：
- 买入角度：某个 Zn 在 Z 之下甚至在 A 之下的，介入风险很大。
- 那些 Zn 缓慢提高、但又没力量突破 B 的，要小心其中蕴藏的**突然变盘风险**，一般构成所谓的上升楔型之类的诱多图形（反向为下降楔型诱空）。
- 中枢震荡中**次级别的类型**很重要：若是趋势类型且 Zn 相应配合，要注意变盘；特别"最后一个次级别中枢在中枢之外的"，一旦下一个次级别走势在该次级别中枢区间完成，震荡就会出现变盘。

## A1 — 书中的应用

### 案例：Zn 曲线作为震荡坐标系（ch92）
- **问题**: 中枢震荡期间如何区分"还能拿"与"该走"。
- **方法论的使用**: 把每个次级震荡区间的中点画成 Zn 曲线，与 Z、A、B 三条水平线对照；观察 Zn 的重心、斜率与是否突破 B/A。
- **结论**: 变盘前 Zn 有可观察的走强/走弱序列，且必然出现一次"超越 A 或 B"。
- **结果**: 把"等三买出现"提前成可量化的走强/走弱读数。

## A2 — 触发场景

1. 用户问"这个中枢震荡是在走强还是走弱"。
2. 用户问"震荡多久了，什么时候会变盘"。
3. 用户在中枢内反复被套，问"这里该不该参与震荡"。
4. 用户怀疑"这里是不是上升楔型诱多"。

### 语言信号

- "中枢震荡还能持续多久"
- "震荡中轴"
- "是不是要变盘了"
- "震荡偏强还是偏弱"

### 与相邻 skill 的区分

- 与 `chanlun-zhongshu-mapper`: 它给中枢边界 A/B 与状态；本 skill 在边界确定后做逐日/逐段读数。
- 与 `chanlun-buy-sell-points`: 本 skill 只预警"变盘临近"，不判定三买是否成立。
- 与 `chanlun-zhongyin-stage`: 中阴阶段的震荡同样适用 Zn，二者可叠加（Zn 看强弱，BOLL 看结束时间）。

## E — 可执行步骤

1. **锁定中枢区间 A、B 与中轴 Z**
   - 完成标准: 用 `chanlun-zhongshu-mapper` 的原文口径给出 [A, B]（A=ZD、B=ZG），算出 Z=(A+B)/2，并画出 A/Z/B 三线。
   - 判停条件: 中枢未确认 → 停止。

2. **标注 Zn 序列**
   - 完成标准: 依次列出每个次级震荡区间 [dn, gn] 的中点 Zn，并按时间编号。
   - 完成标准: 计数 Zn 的个数；**若 > 9，判"次级别已升级"，停止本指标并回到中枢/级别重判**。

3. **判定强弱与重心**
   - 完成标准: 给出每个 Zn 相对 Z 的位置，输出"偏强/偏弱"及趋势（逐步抬高 / 逐步走低 / 无序）。

4. **检查超越与次数**
   - 完成标准: 标出 Zn > B 或 Zn < A 的次数与位置；明确说明"超越可以是多次，只有最后一次才构成第三类买卖点"，此时**不得**因超越直接判三买成立。

5. **给出变盘预警等级**
   - 完成标准: 按以下规则输出预警：
     - Zn 超越 A 或 B 但未构成第三类买卖点 → "中枢震荡级别的扩展概率极高"，给扩展后的更高级别中枢区间估算。
     - Zn 缓慢抬高却无力突破 B → "上升楔型诱多风险"，提示变盘（反向为下降楔型诱空）。
     - 最后一个次级别中枢在中枢之外，且下一个次级别走势在该次级别中枢区间内完成 → "震荡即将变盘"。
     - Zn 重心在 Z 之下（买向）或接近 A → "此位置介入风险很大"。

6. **给出参与性结论（结构层面）**
   - 完成标准: 明确本 skill 的结论只到"可介入性范围"（原文用词），并转 `chanlun-buy-sell-points` 判定是否存在本级别买卖点；若不存在，说明"第二、三买卖点之间都是中枢震荡，本级别没有买卖点，参与需降级到次级别"。

## B — 边界

- 不把 Zn 超越 A/B 当作买卖点；它只是提醒。
- 不在 Zn 个数超过 9 后继续使用本指标。
- 不预测变盘方向（原文只说概率与风险，不说方向）。
- 不替代中枢区间计算：A/B 必须来自原文口径的 [ZD, ZG]。
- 不参与中枢震荡的建议本身（原文明确：最干脆的做法是不参与中枢震荡，只在预先设定的买卖点上买卖；能否参与取决于资金级别与熟练度）。

### 失败模式

- 把第一次 Zn 超越 A/B 就当三买/三卖成立。
- 忽略 Zn 数量上限，在已升级的次级别上继续算中点。
- 只看 Zn 不看 A/B，得出"震荡很强"的错误乐观。
- 把"扩展概率高"表述成"一定要扩展"。
- 把 Zn 指标当作独立指标使用，脱离中枢结构。

### 盲点 / 时代局限

- 原文承认"如果这超越没有构成第三类买卖点……概率是极为高的"，即非绝对；不应作为唯一依据。
- Zn 的取值依赖"次级震荡区间"的划分，划分口径不一致会得到不同曲线。
- 低流动性/跳空品种中，次级震荡区间的中点可能被单根异常K线扭曲。
